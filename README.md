# The Halloween Commit: Horror at the Server Room

## Presentació i entorn

Aquest projecte és una pràctica de Sistemes Informàtics del cicle DAM de l'Escola PIA.

L'objectiu és recuperar un repositori Git afectat per codi maliciós, gestionar branques, resoldre conflictes, restaurar una versió segura i publicar el projecte a GitHub.

**Entorn de treball:**
- Sistema operatiu: Windows
- Terminal: PowerShell
- Editor: Visual Studio Code
- Llenguatge: JavaScript
- Control de versions: Git
